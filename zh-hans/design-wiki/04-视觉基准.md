## 4.1 标准画布

桌面端标准设计基准为：

1920 × 1080，16:9。

六阶段主分镜以这一画布作为初始设计参考。1920 × 1080 不是实际网页的固定尺寸，也不是要求所有屏幕维持 16:9 的画面比例。

实际网页根据视口和容器的可用尺寸连续自适应。统一视觉构图、品牌层级和叙事逻辑，不为桌面、平板、手机、折叠屏或超宽屏单独维护完整页面和动画版本。

设计目标是保持跨屏幕的视觉一致性，而非机械缩小整页。必要时允许局部调整留白、照片可见密度、时间刻度密度与交互控件排列，但不因此改变核心构图语言。详细规则见[第 13 章](15-响应式与可访问性.md#s-13)。

## 4.2 品牌色彩

当前候选色盘：

| 角色 | 色值 |
| --- | --- |
| Canvas · 暖纸白 | #F8F7F3 |
| Ink · 深石墨 | #242B30 |
| Rain Blue · 春夜雨蓝 | #526B79 |
| Surface · 浅白 | #FFFEFB |
| Secondary · 中性灰 | #59666C |
| Border · 浅灰线 | #DBE1E0 |

采用中性色为主体、低饱和矿物蓝为局部强调的策略。

大面积背景不使用强烈品牌蓝。照片保留自身的丰富色彩，不强制使用品牌滤镜。

用户自定义时间标签的颜色独立于品牌调色盘。

## 4.3 字体系统

已选定的品牌展示字体：

中文展示：霞鹜文楷

英文展示：Manrope

正文与功能字体：

中文正文：思源黑体

英文正文：Inter

代码块：Cascadia Code

中文品牌名称、Slogan 和展示标题优先使用霞鹜文楷；Pebril 英文标识及英文展示标题使用 Manrope。

Journal 的正文、导航、技术名称和时间刻度优先保证阅读准确性。

品牌文案避免不必要的中英文混排；技术文章保留 Astro、TypeScript、GSAP、API 等术语的原始名称。

字体角色集中管理，实际字重、字距和字体加载策略在原型阶段进一步验证。
