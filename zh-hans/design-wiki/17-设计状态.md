已确定的设计方向

Quietly Present 的品牌气质。

理性与感性的平衡。

暖纸白、深石墨与低饱和矿物蓝的色彩方向。

1920 × 1080 的桌面设计基准。

霞鹜文楷与 Manrope 的品牌展示字体组合。

思源黑体、Inter 与 Cascadia Code 的功能字体分工。

中央轴线的首屏构图方向。

半隐藏、低焦点、缓慢运动的初始照片河流；照片以溪流同向缓流、落叶式受控微动呈现。

首屏照片以 50% / 约 25% / 15% 的三层露出上限与参考值，以及有动态安全余量的重叠、间距规范组织。

弹性照片包络空间：照片保持原始宽高比，以接近的视觉面积与相对边界适配多种形状；不强制统一 16:9 可见外框。

默认 16:9 网站素材与用户本地照片共享照片容器、六阶段动效和时间轴数据逻辑；本地图片在当前页面会话内处理、不上传服务器。

「春雨成河」动效：照片先随滚动完整显现，再由代表主图先行、后续照片逐张归集，形成轻微扇形图片集，时间轴同步显现。

图片集真实成员数与可见预览分离：前景最多五张照片，更多内容由少量弱化后景层暗示，不把五张误设为容量上限。

归集以主图产生约 20% 遮盖感作为第二张响应的视觉目标，随后第三至第五张依次加入；整段遵循滚动进度、可暂停、可逆。

时间轴在中部保持稳定锚点；图片集位于上方且与真实时间位置对齐，默认无连接线，明确聚焦时才显示轻量辅助关联。

第二屏允许真实交互。

后半段采用「图片集解放 → 河流回归、轻微上扬并渐次远去 → 各图集少量代表照片留痕 → 时间轴低振幅波浪线 → 页脚安静出现」的退场叙事。

「柳梢与溪流」：残留照片如春雨中的柳梢嫩芽，波浪线如其下溪流；常态春雨、轻掠清风和明确操作鸟掠采用不同反馈强度，允许差时、静默和波纹余韵。

页脚与时间轴保持轻量视觉联系。

设计 Token 集中管理。

Single Source of Truth：共享规则、资源与行为具有唯一权威定义。

One System, Adaptive Everywhere：不同视口共享组件、设计语言及六阶段叙事。

Responsive by Composition：以容器和构图约束进行连续自适应，仅在需要时增加局部断点。

以独立开发者的长期维护成本作为设计决策约束。
