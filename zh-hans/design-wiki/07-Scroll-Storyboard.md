## 7.1 动效定义
Memory in Motion — 流动的记忆

这是 Pebril 首页最重要的视觉交互。

同一批照片从第一屏的自由流动状态，先随下滑由半隐藏逐渐完整显现，再以「春雨成河」的方式逐张汇入局部集合、凝聚为图片集，最终与第二屏的时间轴共同形成稳定的时间秩序。

整个过程由用户滚动主导。

动画支持正向和反向变化，不以固定时长强制播放。

<a id="s-7-2"></a>

## 7.2 六阶段分镜

细化规范：[春雨归集](08-Spring-Rain-Gathering.md) · [柳梢与溪流](09-Willow-and-Stream.md)
### Phase 0 · Quiet Flow

首屏初始状态：半隐藏的记忆

品牌、Slogan 与介绍文字占据视觉中心。

照片在首屏底部高低错落、由视口下缘自然裁切；三个视觉露出层级以 50% / 约 25% / 15% 为当前上限与参考目标，具体定义见[第 6.2 节](06-First-Screen-and-Photo-Layout.md#s-6-2)。

照片没有明显的个体焦点，品牌文案保持视觉优先级。

照片显示尺寸由弹性包络空间约束；不同原始比例保留各自轮廓和接近的视觉重量，不强制统一 16:9 卡片。

图片河流整体同向缓流，各照片叠加轻微、连续且受约束的个体微动，如同溪水中的落叶。

时间轴尚未出现。

情绪关键词：隐约、安静、流动。

### Phase 1 · Gentle Gathering

用户开始下滑：先完整显现，再自然汇聚

首屏文字轻微上移或淡出，底部半隐藏的照片随下滑逐渐进入更多可见区域。

整条照片河流充分、完整显现后，用户继续下滑，才开始照片归集；不在照片尚未被看清时提前整体收束。

自主流动平滑让位于滚动进度控制，避免照片跳回预设起点、突然停顿或突兀转向。

每个图片集先选定代表主图；主图率先从当前视觉位置沿柔和曲线缓慢下移，并逐渐缩小，带出局部汇聚方向。

运动隐喻由首屏「溪流中的落叶」过渡为「春雨逐滴归点」。先前的花朵式柔和弧线可以作为路径参考，但不形成具象花朵或雨滴。

情绪关键词：显现、靠近、牵引、自然。

### Phase 2 · Gentle Alignment

照片逐张归集：图片集凝聚成形

主图下移，与邻近照片形成约 20% 的遮盖关系时，第二张开始移动；随后第三、第四、第五张依次加入。20% 为当前视觉目标，实际测量口径和容差留待原型验证。

照片在位移过程中逐渐缩小、减小旋转幅度，最终形成最多五张清晰前景图的轻微扇形层叠，而非完全重合或夸张扑克牌扇面。

当第二、第三张开始归集、图片集轮廓初步成立时，象征集合中其余照片的少量弱化后景层从前景后方缓慢浮现，在第五张归位前后完成视觉深度；优先使用层叠与低对比度，需要时使用克制的模糊。

五张仅是可见预览上限，不是图片集的实际容量上限。不足五张则展示实际数量；更多照片仍属于图片集，不要求每张都作为独立的后景卡片渲染。

多个图片集可以轻微错峰凝聚，但属于同一连续滚动叙事；时间轴在图片集逐步成形时就开始缓慢显现，不等待所有图片集完全形成。

保留「卡牌式整序」的轻微叠放与对齐规律，但整体以「春雨凝聚成集」为主导意象，不形成水滴实体、碰撞效果或机械排队动画。

情绪关键词：逐滴、凝聚、层叠、归整。

### Phase 3 · Timeline Reveal

第二屏成立：图片集与时间轴同步稳定

时间轴在画面中部、相对固定的布局锚点上逐渐增加可见度，不从边缘飞入，也不大幅移动或缩放。

图片集沿各自轨迹逐渐下移并停在时间轴上方，与相应的真实时间位置对齐，保留恰当的呼吸空间，不与时间轴发生视觉碰撞或弹跳。

时间轴显现与图片集归位共享滚动进度并部分重叠进行：图片在形成秩序的同时，承载它们的时间结构也逐渐清晰；不是先完成其一、再播放另一段。

时间刻度、集合与时间位置的对应关系，以及第二屏标题与提示，随后轻柔补足；稳定状态可直接进入时间轴交互。

最终默认不绘制图片集到时间轴的常驻连接线，依靠空间对齐表达关系；仅在明确聚焦或选中时显示辅助关联，见[第 8.3 节](10-Timeline-Exploration.md#s-8-3)。

时间轴应呈现一种「它原本就在这里，只是现在被看见」的感觉。

参考克制的 Apple 式产品展示节奏，但保持 Pebril 自己的视觉语言。

情绪关键词：显现、稳定、精确。

### Phase 4 · Quiet Dissolution

继续下滑：从图片集释放为河流

第二屏先保留足够的稳定浏览空间；用户继续下滑时，图片集解除轻微扇形层叠，前景照片逐渐恢复为具有不同轮廓和姿态的独立照片。

后景弱化层逐渐退去，独立照片重新形成与第一屏呼应的同向缓流；不完整倒放「春雨成河」的逐张归集过程。

河流以横向流动为主、轻微向上舒展为辅，逐步释放页脚上方的留白。大多数照片沿原有流向渐次离场，不突然飞散或集体淡没。

每个图片集的前三张代表照片保留为更松散的局部残留群组（实际不足三张时按真实张数），不继续保持完整图片集结构；它们在原时间位置附近留下视觉余韵，形态联想到柳树末梢的嫩芽，而非组成具象水纹。

时间轴的刻度、标签和交互强调逐渐减弱，主体线条保留平稳的空间锚点，缓缓过渡为页脚上方一条低振幅、长波长的柔和波浪分隔线。

退场的主要动作仍由滚动位置统一控制、可逆；时间轴与页脚之间为视觉连续关系，不强制将时间轴所有子元素变形为页脚组件。具体实现见[第 7.4 节](09-Willow-and-Stream.md#s-7-4)。

情绪关键词：松开、回流、舒展、留痕。

### Phase 5 · Quiet Closure

页脚出现：柳梢与溪流的安静余韵

页脚品牌名称、Slogan 和 Journal、GitHub、X 等链接在稳定留白中轻柔浮现，不再制造新的动画高潮。

上方保留的少量照片群组近乎静止，像柳梢末端的嫩芽，只在合适时机发生微弱、非持续的自然扰动。

下方波浪线兼作最后一屏与页脚之间的结构分隔；在少量局部位置，对上方照片的微动或用户交互作出不完全同步、具有差时与衰减的涟漪回应。

用户明确点击、触控或键盘激活时，应得到及时且可感知的反馈；非主动状态允许长时间安静，不要求照片每次微动都触发波纹。

波浪线和照片的联动不应妨碍阅读、链接点击、焦点可见性及页面滚动；系统减少动态效果设置下应采用静态或显著简化呈现。

整个页面最终不是绝对静止，而是静中有动、动而不扰，让「时间仍在向前、记忆仍有回响」留在页脚上方。

情绪关键词：平静、回响、留白、余韵。

<a id="s-7-5"></a>

## 7.5 关于转场力度
正式采用以下区分：

前半段负责显现，后半段负责收束。

第一屏到第二屏可以使用较完整的照片汇聚、归整与时间轴显现过程。

第二屏到页脚不应继续制造同等强度的视觉表演。

用户最应该记住的是时间轴的出现与产品体验，而不是页脚动画。

<a id="s-7-6"></a>

## 7.6 滚动行为
滚动动画必须满足：

进度由用户的滚动位置决定。

允许反向滚动恢复之前的状态。

停止滚动时，滚动叙事的构图与关键位置保持稳定；[第 7.4 节](09-Willow-and-Stream.md#s-7-4)的页脚常态微动属于独立且受约束的余韵层，不推进滚动叙事进度。

不强制自动播放整段转场。

不通过长时间锁定滚动妨碍阅读。

自主照片运动与滚动控制不会发生冲突；进入或退出滚动叙事时，照片位置与速度感应连续衔接，避免突兀跳变。

不同视口共享同一套六阶段状态与滚动进度模型；动画坐标应优先基于场景容器及其锚点计算，不依赖单一固定像素画布。

视口变化时可以调整运动距离、图片密度与必要布局约束，但不维护独立的设备专属叙事实现。

具体滚动区间、缓动曲线、移动路径与时间比例，留待正式分镜和原型验证。
