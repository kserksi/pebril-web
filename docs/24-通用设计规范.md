## 1. 设计立场

### 1.1 三条不可让渡的原则

1. **安静（Quietly Present）** —— 界面不喊人。不用纯黑纯白、不用高饱和色、不用渐变、不用投影堆叠、不用弹跳动画。信息在场，但不抢照片。
2. **照片优先（Images Come First）** —— 任何界面上，照片的视觉权重高于容器、边框、控件和文字装饰。装饰要让路，不能盖住画面。
3. **一套系统（One System, Adaptive Everywhere）** —— 同一个 Token、同一套组件，官网、手记、应用界面共享；差异只来自版面与密度，不来自另一套配色或另一套字。

### 1.2 这三条原则怎么落地（四条规则）

| 决定 | 落地方式 |
|---|---|
| 单一事实来源 | 颜色、字号、间距、圆角、动效只在一处定义（附录 A 的 Token 块），组件只引用角色变量，不复制数值 |
| 容器轻、内容重 | 卡片用 1px 细线 + 浅底，不用重阴影；照片容器边框 5px 纸色，模拟相纸 |
| 动效服务于理解 | 每个动效都要能回答「它在解释什么」；解释不了的去掉 |
| 可维护优先于可炫技 | 零依赖优先；引入动画库必须能说清换来了什么 |

## 2. 色彩

### 2.1 角色与取值

| Token | 值 | 对比度（对画布） | 用途 | 可以承载文字吗 |
|---|---|---|---|---|
| `--canvas` | `#f8f7f3` | — | 页面底色、卡片外底 | 否 |
| `--wash` | `#f1efe8` | — | 次级底色：引用块、行内代码底、选中行 | 否（上面放正文色） |
| `--ink` | `#242b30` | 13.39:1 | 正文、主要标题、图标 | 是（AAA） |
| `--secondary` | `#59666c` | 5.53:1 | 说明文字、日期、导航、副标题 | 是（AA，≥12px） |
| `--accent` | `#526b79` | 5.24:1 | 链接、可交互文字、焦点描边、进度 | 是（AA） |
| `--ring` | `#bfc4c1` | 1.65:1 | 装饰性描边、未激活刻度、圆环 | **否**，不可承载文字，不可作为唯一状态指示 |
| `--rule` | `#e3e0d8` | — | 分隔线（1px） | — |
| `--rule-strong` | `#cfcbc0` | — | 输入框边框、需要看清的结构线 | — |
| `--mist` | `167 182 164`（RGB 分量） | — | 选中高光 `rgb(var(--mist) / .3)`；需要透明度时用它 | — |

**规则**

- 画布永远是 `--canvas`，不要用 `#fff`；正文永远是 `--ink`，不要用 `#000`。这两条是品牌识别的一半。
- 一屏之内只用三种文字色：`--ink`（主）、`--secondary`（辅）、`--accent`（可点）。不引入第四种灰。
- 强调色只给「可以点」和「正在进行」的东西。正文里不要用强调色装饰关键词。
- `--ring` 只做装饰线；任何需要被看清的边界（输入框、可选中的卡片）用 `--rule-strong`。

### 2.2 用色比例（经验值，非硬指标）

背景 85% ／ 文字 10% ／ 线 4% ／ 强调 ≤1%。任何时候，把界面截图缩成缩略图，应当仍是一张「浅色纸」，而不是一块有颜色的界面。

### 2.3 语义色（提案，未冻结）

应用界面需要成功／警告／错误，官网没有这些状态。下表是在本族色相内取的候选值，均已核对比度 ≥ 4.5:1（对画布），**需 owner 批准后写入 Token**：

| 角色 | 提案值 | 对比度 | 用途 |
|---|---|---|---|
| `--success` | `#4f6b57`（静绿） | 5.48:1 | 完成、已保存、健康 |
| `--warning` | `#8a6136`（赭） | 5.10:1 | 需要注意但不阻断 |
| `--danger` | `#8a4a45`（砖红） | 6.23:1 | 删除、失败、不可恢复 |

用法约束：语义色只出现在图标、状态点、1px 边框、以及一行文字里；**不做整块彩色背景**。若需要底，取 `rgb(var(--mist) / .18)` 一类的极浅wash，文字仍用语义色本身。

### 2.4 禁用

- 渐变（含背景渐变、文字渐变、光晕）。
- 纯黑 `#000`、纯白 `#fff` 作为大面积底。
- 玻璃拟态／毛玻璃卡片（唯一的例外是照片查看器的 `::backdrop` 模糊，那是为了让人专注一张照片）。
- 彩虹式状态色板；同一语义在不同页面换色。
- 用颜色单独表达状态（必须配文字或图形）。

## 3. 字体与排版

### 3.1 字体角色

| Token | 字体栈 | 用在哪 |
|---|---|---|
| `--display-en` | `'Manrope', system-ui, sans-serif` | 品牌字 Pebril、英文大标题、eyebrow、数字日期 |
| `--display-zh` | `'Pebril Kai', 'LXGW WenKai', 'KaiTi', 'STKaiti', serif` | 中文标题、品牌中文「溪石」、图片集名 |
| `--sans`（正文） | `system-ui, -apple-system, 'Segoe UI', 'PingFang SC', 'Hiragino Sans GB', 'Microsoft YaHei', 'Noto Sans CJK SC', sans-serif` | 所有正文、UI 文案、表单、表格 |
| `--mono`（可选） | `ui-monospace, 'SFMono-Regular', 'Cascadia Code', 'Consolas', monospace` | 代码、路径、ID（应用界面用） |

**三条硬规则**

1. **文楷只用于标题与品牌**，不用于正文、按钮、表格、表单标签。它是「手写感的署名」，用多了会糊。
2. **正文用系统栈，不自托管正文西文字体**。收益（跨平台熟悉度、零加载）大于定制感；且中文回退字形在中国用户的系统里本来就最合适。
3. **子集化字体只允许出现在需要的那几个字上**。官网把文楷裁成 76 字（12KB）、Manrope 裁成 6 个字形（14KB）；父项目若用文楷做标题，必须按「实际用到的标题字符集」构建子集，并在标题变更后重建（脚本见 `tools/build-kai-font.sh`、`tools/build-brand-kai-font.sh`）。

### 3.2 字号阶梯

只允许下列档位（`clamp()` 的中间值是桌面基准）：

| 名称 | 值 | 行高 | 字距 | 用途 |
|---|---|---|---|---|
| `--text-2xs` | 10px | 1.5 | `.22em`（英文大写）／`.08em` | eyebrow、法务小字、刻度标签 |
| `--text-xs` | 12px | 1.7 | `.035em`–`.12em` | 导航、按钮、日期、辅助说明 |
| `--text-sm` | 13px | 1.8 | `.03em` | 表格、次级正文、表单标签 |
| `--text-base` | 17px | 1.85–1.95 | `.008em` | 正文（手记、说明文） |
| `--text-md` | `clamp(13px, 1.2vw, 17px)` | 1.9 | `.08em` | 相册副文一类「有呼吸的说明」 |
| `--text-lg` | `clamp(17px, 1.6vw, 21px)` | 1.7 | `.02em` | 引导句、卡片标题 |
| `--display-sm` | 21–28px | 1.35 | `-.04em`（英文）／`.06em`（中文） | 手记品牌、收尾品牌 |
| `--display-md` | `clamp(27px, 3.2vw, 42px)` | 1.45 | `.035em` | 区块标题（如收尾主标题） |
| `--display-lg` | `clamp(32px, 4.5vw, 66px)` | 1.5 | `.035em` | 页面主标题（每页最多一个） |
| `--display-xl` | `clamp(40px, 5vw, 72px)` | 1.25 | `-.045em`（Pebril）／`.13em`（溪石） | 品牌字，仅首屏/品牌页 |

**应用界面的标题映射**（父项目建议）：

- h1 = `--display-md`（应用页不需要 66px 的宣言）
- h2 = `--text-lg` + `--ink`
- h3 = 17px 正文重体（不换字体）
- 卡片标题 = `--text-base` + `--ink`（不用文楷）
- 数据表头 = `--text-xs` + `--secondary` + `.06em` 大写（中文用 `.04em`，不强制大写）

### 3.3 行长与段落

- 中文正文阅读栏 **40rem**；移动端 `max-width: 23em`。超过 32 字/行中文就很难读。
- 段落间距 `1.1em`–`1.3em`；段落之间**不用空行、不用首行缩进**（这是中文网页的现代默认）。
- 不用两端对齐（`text-align: justify`）；用默认左对齐 + `text-wrap: pretty`。
- 中英混排：数字、英文与中文之间不加空格，靠字体的 `letter-spacing` 与全角标点自然分开；**标点用中文全角**（，。：；「」），英文缩写/版本号内部用半角。
- 数字：日期用 `tabular-nums` 等宽数字；`2024.06.08` 这种点分格式只用于照片时间。

### 3.4 标点规则（来自品牌文案规范）

- 标题、Slogan、品牌名、短标签：**句末不加句号**。
- 正文、隐私说明、错误提示、帮助文字：正常标点。
- 不用感叹号；不用「哦」「啦」一类语气助词。

## 4. 空间、网格与响应式

### 4.1 间距阶梯

以 4px 为基准，只允许：`4 / 8 / 12 / 16 / 20 / 24 / 32 / 40 / 56 / 72 / 88`。

例外（历史实现，保留但不推广）：相纸边框 5px、`.explore` 的 `padding: 12px 24px`。圆角不属于间距，见第 5 节。

**关系规则**

- 同组元素之间用 8–12px；分组之间 20–24px；区块之间 40–72px；页首/页尾 56–88px。
- 垂直间距永远大于水平间距（同一层级内），让版面「站得住」。
- 卡片内部：上 20px、左右 24px、下 24px（底部略大于顶部，视觉上更稳）。

### 4.2 容器与页边距

| 场景 | 宽度 | 页边距 |
|---|---|---|
| 阅读/表单栏 | `40rem` | `clamp(20px, 5vw, 56px)` |
| 应用主内容 | `78rem` | 同上 |
| 全宽舞台（首屏、照片河） | 100% | 0（元素自己算安全边） |

### 4.3 断点

| 名称 | 范围 | 主要变化 |
|---|---|---|
| `xs` | < 600px | 单列；导航压缩到 72px 高；页边距收到 20px；条件允许时把触控目标提到 44px |
| `sm` | 600–767 | 单列 + 更宽页边距 |
| `md` | 768–1023 | 双列起步；表格允许横向滚动而不是压缩 |
| `lg` | 1024–1279 | 侧栏出现（应用界面建议 240px） |
| `xl` | 1280–1724 | 内容最大宽度生效 |
| `2xl` | ≥ 1725 | 大屏：卡片尺寸到上限（500px），不再随视口放大 |

流体写法优先用 `clamp()` 一次表达，而不是写 6 个媒体查询；只有结构性变化（列数、侧栏）才写断点。

### 4.4 密度与触控

- 任何可点区域 **≥ 40×40px**（应用界面的表格行高 ≥ 44px，图标按钮 40×40）。
- 行内链接、图标按钮的**视觉尺寸可以小，命中区域用 padding 补足**。
- 相邻可点元素之间至少 8px，避免误触。

## 5. 形状、边框与层次

| 元素 | 圆角 | 边框 | 阴影/底色 |
|---|---|---|---|
| 按钮（主/次） | 8px | 1px `--rule-strong`（次要按钮） | 主按钮：`--ink` 底 + `--canvas` 字；次按钮：透明底 + `--ink` 字 |
| 文件选择 / 输入 | 10px | 1px `--rule-strong` | `--canvas` |
| 卡片 / 操作入口 | 12px | 1px `--rule` | `0 3px 16px #242b3012` 或纯线 |
| 对话框 / 浮层 | 12px | 无 | `0 8px 32px #242b3014` |
| 提示条（privacy/inline note） | 12px | 1px `--rule` | `--wash` |

- 阴影只用这两级，且**不要与重边框同时出现**。线优先于影。
- 不用「卡片套卡片」。需要分组时用间距与一条细线，而不是再加一层容器。
- 深色底块（`--ink`）只用于主按钮和极少数强调块，一屏不超过一两个。

---

## 6. 图标

- 线性图标：1.5px 描边、圆头端点、24×24 视框、实际视觉尺寸 16/20/24。
- 与文字并排时，图标垂直居中，与文字间距 8px；图标颜色继承文字色，不单独上色（语义色除外）。
- 图标不做装饰背景（不用圆形色块托底）。
- 照片、Logo、品牌字不放图标；已有品牌字的地方不再配 Logo。
- 交付格式：内联 SVG（可继承 `currentColor`），不使用图标字体。

## 7. 组件

> 每个组件写「结构—尺寸—状态—键盘—文案」。数值以线上实现为基准，可以直接照抄；属于提案的部分已就地注明。

### 7.1 按钮

**主按钮**（一屏最多一个；官网没有填充按钮，这一形态为父项目新增提案，配色仍只取 `--ink` / `--canvas` 两个 Token）

```
高度 40px；水平内边距 20–24px；圆角 8px；
背景 --ink；文字 --canvas；字 13px/500；字距 .04em；
hover：背景不变，透明度 .92；active：translateY(1px)；
focus-visible：outline 2px --accent，偏移 4px；
disabled：背景 rgb(var(--mist) / .5)，文字 --secondary，不接收指针事件
```

**次按钮 / 描边按钮**（官网的「选择本地照片」「清除并恢复示例」即此形态）

```
高度 40px；1px --rule-strong（或 --ring）边框；圆角 10px；透明底；文字 --ink；
hover：底色 --wash；active：translateY(1px)
```

**文字按钮 / 链接式**：`--accent` 文字，无下划线，hover 时加 1px 下划线（`text-underline-offset: 3px`）。

**图标按钮**：40×40，无边框，hover 底 `--wash`，图标 20px。

**规则**：一个视图里主按钮不超过 1 个；按钮文案 2–6 个字，动词开头（「选择本地照片」「保存」「重试」），不用「点击这里」。

### 7.2 链接

- 正文内链接：`--accent`，hover 加下划线；访问过不变色（相册/文档类站点不区分 visited）。
- 卡片整体可点：整块是 `<a>`，内部文字颜色不变，hover 时卡片 `translateY(-2px)` + 阴影加深一档。
- 外链：不改颜色，不加外链图标（保持安静）；在 `title`/`aria-label` 里说明会离开本站。

### 7.3 输入与文件选择

```
标签：在控件上方，13px，--secondary，与控件间距 6px
控件：高 40px，圆角 10px，1px --rule-strong，底 --canvas，内边距 12px，
     字号 15–17px，占位符 --secondary
聚焦：边框变 --accent + outline 2px（不用 box-shadow 代替）
错误：边框 --danger，下方 12px 错误文字（--danger），并加 aria-describedby
帮助文字：12px --secondary，与控件间距 6px
```

**文件选择**（照片导入的主入口，官网已验证的形态）

```html
<label class="file-choice">
  <span class="file-choice-label">选择本地照片</span>
  <input type="file" accept="image/jpeg,image/png,image/webp" multiple>
</label>
```

- 控件本体视觉隐藏但不能 `display:none`（保留键盘 Tab）；用 `label` 承接点击。
- 拖拽区：虚线换成 1px `--ring` 实线 + `--wash` 底；拖入时边框 `--accent`，其余不变。
- 处理中：把「选择本地照片」换成「正在读取照片与拍摄日期…」，不做转圈动画超过 1 秒（用文字 + 一条 2px 进度线即可）。

### 7.4 卡片

- 结构：`图/图标 → 标题 → 一句说明`，垂直排列；不放大段正文。
- 操作入口卡（官网收尾的三入口）：`aspect-ratio: 1`、`max-width: 420px`、三列网格、`gap: clamp(12px, 3vw, 24px)`。
- hover：`translateY(-2px)`，220ms；不做缩放、不做颜色反转。
- 整卡可点时，键盘焦点落在卡上，`focus-visible` 用 2px 描边。

### 7.5 列表条目（手记 / 图片集）

- 条目之间 1px `--rule` 分隔，**不用卡片、不用斑马纹**。
- 元信息在标题上方：日期 12px `--secondary` + `tabular-nums`；标题 17–21px `--ink`；一行摘要 15px `--secondary`。
- hover：只有标题颜色微调（`--ink` → `--accent` 或加下划线），其余不动。

### 7.6 导航

- 顶部导航高 88px（移动 ≤600px 为 72px），左侧品牌、右侧链接，字号 12–13px，字距 `.035em`，颜色 `--secondary`。
- 当前页：文字变 `--ink`，不加下划线、不加背景。
- 页脚：一条 1px `--rule` 起，法务/版权 10px `--secondary`，链接与正文同色。
- 面包屑（应用界面用）：12px `--secondary`，分隔符 `/`，当前项 `--ink`。

### 7.7 状态标签

用于区分类别（如手记的「已实现的功能 / 已确定的原则 / 仍在探索的想法」）：

```
12px；--secondary；前不缀图标；与正文之间用一个空格或 8px 间距；
需要区分强弱时，只允许改颜色（--secondary / --accent / --danger），不添加底色
```

### 7.8 对话框

- 优先用原生 `<dialog>` + `showModal()`，自带焦点陷阱与 Esc。
- 面板：圆角 12px，内边距 20px，1px `--ring` 边框；宽度按内容算（官网查看器是「`max(220, 图片宽 × 缩放) + 40px`」，上限 `100vw - 32px`），`max-height: calc(100svh - 32px)`。
- 背景 `::backdrop`：`blur(8px)` + `#242b3066`；过渡 440ms `cubic-bezier(.2,.75,.2,1)`；关闭时反向，先移除 `is-visible` 类，并强制读取一次 `::backdrop` 的计算样式以刷新动画起始帧。
- 焦点：打开时聚焦主操作或标题；关闭后焦点返回触发元素。
- 文案：标题一句话；说明最多两行；按钮「关闭」在左或右固定一个位置，不要两处都有。

### 7.9 提示、空状态与错误

- 空状态：一句安静的话 + 一个动作（「还没有照片。选择本地照片，或稍后查看示例。」）。
- 加载：优先用文字（「正在准备照片与字体」），配一条 2px、`--accent` 的低调进度线；不用骨架屏闪光。
- 错误：说明发生了什么 + 下一步能做什么，不出现堆栈、不出现「未知错误」。
- 行内提示条（如「仅在当前浏览器读取，不上传、不保存」）：`--wash` 底、1px `--rule`、12px `--secondary`、圆角 12px。

### 7.10 跨场景照片组件边界

只定义规则，不定义文件名（见 [12-设计系统](12-设计系统.md) 10.4）：

- **照片卡**：容器边框 5px `#fffefb`（相纸感），底色 `#e1e3dc`，阴影 `0 3px 16px #242b3012`；图片 `object-fit: cover`，必须带 `width/height` 与 `srcset/sizes`。
- **集合/相册**：以日期或标题为一等公民；成员数量以文字说明（「图片集 3 · 5 张」），不用数字徽章。
- **查看器**：全成员浏览、键盘左右、Esc 关闭、原图比例、加载与失败态；打开起点与当前选中项同源。
- **时间轴**：中心固定指针 + 单一读数；快速滑动放大区间；长空档破折显示；吸附附近节点；减动效时静态对齐。

## 8. 动效

### 8.1 原则

1. 动效解释状态，不表演。每一次位移都应该对应「从哪来、到哪去」。
2. 慢，但短。缓动前段快、后段极缓（`cubic-bezier(.2, .75, .2, 1)`），观感是「轻轻放下」。
3. 一切都可逆。滚动、打开、切换都要能原路返回，且返回不产生残影。
4. 用户说停就停。`prefers-reduced-motion: reduce` 时，动画时长归零、位置直接到终态，只保留透明度变化（或干脆没有）。

### 8.2 时长阶梯

| Token | 值 | 用途 |
|---|---|---|
| `--dur-instant` | 120ms | 离场、悬停淡出 |
| `--dur-quick` | 180ms | 入场、提示出现 |
| `--dur-base` | 220ms | 卡片悬停、按钮按压、链接反馈 |
| `--dur-view` | 270ms | 跨页面过渡总时长 |
| `--dur-panel` | 440ms | 对话框/查看器开合 |
| `--dur-brand` | 1500ms | 品牌字交替（Pebril ↔ 溪石） |

### 8.3 位移与不透明度

- 入场位移 ≤ 6px，离场 ≤ 3px，方向与来源一致（从下方来，向上进）。
- 缩放只在照片包络/查看器前后呼应时使用，范围 0.75–1；界面控件不做缩放。
- 透明度过渡用于「换页/换态」，不用于「悬停」。
- 不做弹跳（bounce/elastic）、不做旋转（除照片本身 ±8° 的倾角）、不做循环闪烁（呼吸允许 ±1.2% 的极缓振幅）。

### 8.4 跨页面过渡（已实现，可直接复用）

- 用原生 View Transitions：旧文档 `<style>@view-transition { navigation: auto }</style>` 必须**内联在首帧之前**（放在外部 CSS 里会在快通道导航中被跳过）；CSP 用 `<style>` 的哈希放行。
- 离场 120ms（`1 → 0`，`translateY(-3px)`），留 90ms 的纸面空拍，入场 180ms（`0 → 1`，`translateY(6px) → 0`）；总 270ms。
- 跨文档时，`view-transition-name` 只给真正共享的元素（如手记品牌字）；对不配对的快照要显式压制：

```css
::view-transition-group(journal-brand),
::view-transition-old(journal-brand) { animation: none !important; opacity: 0; }
```

- 到达方文档决定动画；想在「进入首页」时用不同节奏，就在首页写规则。

### 8.5 性能底线

- 只动 `transform` 与 `opacity`；不动 `width/height/top/left`（会重排）。
- 连续动画（照片微动、呼吸）用 `requestAnimationFrame` 统一驱动，一帧内一次写入。
- 图片先解码再入场；未解码的图不得参与布局计算（否则首帧几何为空，会算出 `NaN`）。
- 长列表/大图必须懒加载：`loading="lazy"` + `decoding="async"`，首屏主图用 `fetchpriority="high"`，并给 `srcset/sizes`。
- 单页新增的 JS 预算：首屏关键脚本 ≤ 100KB（未压缩）；第三方脚本默认不允许（字体也自托管）。

## 9. 可访问性

- 正文对比度 ≥ 4.5:1，大字 ≥ 3:1；装饰线不做对比度要求但不能承载信息。
- 焦点必须可见：`outline: 2px solid var(--accent); outline-offset: 4px`；不允许 `outline: none`。
- 键盘可达：所有交互元素可 Tab、可 Enter/Space 激活；对话框内焦点循环，Esc 关闭，关闭后回到触发点。
- 语义化：一个页面一个 `h1`；列表用 `ul/li`；导航用 `nav` + `aria-label`；图片必须有 `alt`（装饰图 `alt=""`）。
- 状态播报：动态文案（加载进度、复制成功）用 `aria-live="polite"`，不打断当前朗读。
- 触控：目标 ≥ 40×40px；不依赖 hover 才能发现的功能。
- 减少动态：`@media (prefers-reduced-motion: reduce)` 里关闭所有位移/循环动画，保留终态。
- 语言：`<html lang>` 必须正确；中英混排页面用 `lang` 属性标注片段。

## 10. 文案

### 10.1 语气

安静、具体、不承诺。用「它做什么」代替「它多好」；用短句代替排比；不出现「极致」「颠覆」「一站式」这类词。

### 10.2 用词表（中文权威）

| 概念 | 用 | 不用 |
|---|---|---|
| 图片的集合 | 图片集 | 相册集、图库、album |
| 按时间浏览 | 时间漫游 | 时间轴探索（作为场景名时两者可互换，正文统一「时间漫游」） |
| 手记 | 手记 | 博客、文章列表 |
| 本地预览 | 本地照片 | 上传预览 |
| 未知日期 | 时间未知 | 无日期、日期缺失 |
| 加载 | 正在准备照片与字体 | Loading… |
| 动作 | 选择本地照片、清除并恢复示例 | 上传、导入（本地预览场景下） |

### 10.3 标点与大小写

- 中文用全角标点；英文产品名 `Pebril` 首字母大写、不加冠词；「溪石」仅在中文语境出现。
- 标题、Slogan、短标签不加句号；正文正常断句。
- 数字与单位之间不加空格（`5 张`、`25 张` 保留一个空格，这是中文排版惯例）。
- 日期：照片时间用 `2024.06.08`；界面时间用 `2026-11-01`。

### 10.4 状态与错误文案模板

| 场景 | 模板 | 示例 |
|---|---|---|
| 加载中 | 正在 + 动作 | 正在准备照片与字体 |
| 空 | 事实 + 一个可做的动作 | 还没有照片。选择本地照片，或稍后查看示例。 |
| 失败 | 发生了什么 + 怎么办 | 这张照片暂时无法显示，请切换查看其他照片 |
| 成功 | 一句过去式 | 已加入 5 张本地照片 |
| 隐私 | 边界 + 不做什么 | 仅在当前浏览器读取，不上传、不保存 |
