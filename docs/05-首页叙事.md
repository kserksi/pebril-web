# 首页总体叙事

> 来源：官网设计白皮书 v0.3 · 原白皮书第 5 章。保留原文的已确定、候选和待验证状态。

<a id="s-5"></a>

首页以两大主要场景及其滚动过渡构成：

第一屏：品牌与照片河流

第二屏：时间漫游与图片集

随后进入简洁页脚。

完整的视觉叙事为：

静谧流动 → 自然汇聚 → 层叠整序 → 时间显现 → 交互探索 → 安静收束。

这条路径不仅是视觉过渡，也是 Pebril 核心产品理念的表达。

第一屏到第二屏，呈现照片逐渐形成秩序的过程。

第二屏到页脚，使已经形成的结构逐渐退回安静的背景状态，让品牌叙事自然结束。
