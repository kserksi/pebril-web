## 2026-11-01 · 回到首页也是同一张纸

- 「返回官网」现在与手记内部的跳转同速同形：首页也 opt-in 跨文档视图过渡，旧页 120ms 收住、新页 90ms 后以 180ms 淡入；手记 → 官网、官网 → 手记两个方向都是一次呼吸，而不是硬切。
- 首页的过渡规则写在内联 `<style>` 里，而不是 `src/styles.css`。跨文档过渡只认「首次样式解析时已存在」的 `@view-transition`，外链样式表在快网络下偶尔晚到一帧，会让过渡被静默跳过（实测约两成）。内联版本用 CSP 哈希放行（`style-src 'self' 'sha256-…'`），`index.html` 里写了注释：改动这段字节必须同步重算哈希。
- 手记品牌字带 `view-transition-name: journal-brand`，回到首页时没有对应元素，首页 CSS 把这条游离快照设为 `opacity: 0`，避免小小的「Pebril 手记」叠在序章上。
- 品牌与序章自身的动效一概未改：过渡只覆盖导航那一瞬，落地后 Prelude 仍按原来的加载、涟漪与收敛序列运行。
- 回归：`qa/tests/journal-transition.browser.test.mjs` 增加第二个用例，真实点击「返回官网」，断言 `pagereveal` 带过渡、动画名为 `site-arrive`/`site-leave`、内联规则通过 CSP、减动效下不播放；并验证落地后序章照常启动、首屏提示仍是 `<p>`。

## 2026-11-01 · 首屏提示改为静读，手记页间有了呼吸

- 首屏底部的「向下，慢慢展开 ↓」不再是按钮：`index.html` 里由 `<button class="explore">` 改为 `<p class="explore">`，取消 `pointer-events` 与 `cursor: pointer`，并删掉 `src/prelude.mjs` 中「点击滚到相册」与「聚焦时扰动涟漪」两处监听。提示仍在原位轻轻漂浮，但点它只会在纸面上落下一圈涟漪，不会代为滚动；需要翻过序章时，键盘用户按 PageDown 即可。
- 手记的页间跳转改为纯 CSS 跨文档视图过渡（`@view-transition { navigation: auto; }`）：离页用 160ms 收住并上移 4px，新页在 170ms 后以 180ms 从下方 10px 处淡入（两页快照不重叠，文字不会重影），缓动沿用站点的 `cubic-bezier(.2, .75, .2, 1)`；品牌「Pebril」由 `view-transition-name: journal-brand` 在索引、文章与中英文之间保持连续。`prefers-reduced-motion: reduce` 下不播放过渡。手记依旧是零脚本页面。
- 测试随契约更新：`qa/tests/browser.test.mjs`、`motion.browser.test.mjs` 改为断言提示的 `tagName`、`pointer-events`、`cursor` 与「点它不滚动」，翻页改用键盘 PageDown 或直接滚动；新增 `qa/tests/journal-transition.browser.test.mjs`，用 `pagereveal` 与动画名 `journal-arrive` 证明过渡真的发生，并单独验证减动效路径。
