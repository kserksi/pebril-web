页脚用于收束品牌叙事。

主要包含：

Pebril / 溪石

你的图片，自有归处。

以及 Journal、GitHub、X、必要隐私与法律信息。

页脚与时间轴的连接是视觉意象上的延续，而不是功能上将时间轴直接变成页脚。时间轴主体线条可以逐渐弱化为低振幅波浪分隔线；其上方少量残留照片与分隔线形成「柳梢与溪流」的局部、差时呼应（见[第 7.4 节](09-柳梢与溪流.md#s-7-4)）。

页脚本身必须保持清晰、稳定、容易操作。波浪线不占据额外的交互主导权，也不影响 Journal、GitHub、X 等链接的可达性。

## Implemented local closure · 2026-10-25

The three project actions belong to the third scene. The duplicate discovery link has been removed; its GitHub destination remains available through the rounded-square GitHub entry. It contains the brand, existing approved slogan, truthful development status, stable action links, native local-photo privacy disclosure and the repository's MIT/copyright attribution. The back-to-top control was removed following the owner's second visual review. The footer replaces the earlier generic photography attribution bar. No reference-image prose was copied.

Owner-confirmed destinations: Journal `/journal`; X `https://x.com/pebril_dev`; GitHub `https://github.com/kserksi/Pebril`. The owner explicitly selected link wiring only for Journal in this iteration: no Journal content page or placeholder was created, so the local static preview does not implement that route. The fixed header is absent from scene two; third-scene actions use responsive rounded squares. The legal/privacy band is sized by its contents near the bottom, with the stream divider above it. Following the latest owner correction, independent river photos return above the brand instead of remaining at the bottom. Privacy opens as a native floating text popover, closes by Escape/outside activation or its close control, and does not enlarge the legal band. Privacy wording describes browser-session preview and capture-date reading, with no upload or persistent storage.
