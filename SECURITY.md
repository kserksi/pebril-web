# Security policy

This repository publishes a static site: HTML, CSS, ES modules, images, self-hosted font subsets and a pre-built Hugo journal. There is no server-side code, no accounts, no cookies and no analytics here, and the published pages make no third-party requests. Local photo previews run entirely in the browser and never leave the machine.

That scope limits, but does not remove, the risk: a compromised dependency, a tampered asset, a content injection through the Journal source or a misconfigured host can still affect visitors.

Report suspected vulnerabilities privately through [GitHub private vulnerability reporting](https://github.com/kserksi/pebril-web/security/advisories/new). Do not include credentials, real user photos or exploit details in a public issue. Include the affected URL or commit, the browser, reproduction steps with synthetic data, the impact you observed, and any suggested mitigation. No response-time or supported-version guarantee is currently offered.

The product repository documents its own security posture; this file covers only the website and journal in this repository.
